# Tessera engineering notes — the measured laws

Everything here was established by measurement on real renders;
failed hypotheses are recorded next to the ones that survived.
This is the long-form reference behind the README's defaults.

# The tiled refiner

Feed it the latent of an already-upscaled plate (neutral resampler — lanczos).
It splits the plate into training-distribution windows and refines each window
with **exact per-tile conditioning**: the tile's own crop of the video
reference, the image reference, the in-band guide, and (with `clip` wired) a
text embedding re-encoded from the tile's own crop of the reference media.
Tiles are sampled over a single shared noise field and composited with
weight-normalized crossfades in both latent and pixel space.

## The core idea: anchor every tile to the truth, not to its neighbours

Earlier versions (and the V1 nodes) used **sequential frozen-border
refinement**: each tile's border was held out of denoising and carried the
already-refined output of its neighbours, so texture statistics propagated
forward and no cell was generated twice.

That design is superseded for H3. With full per-tile conditioning each tile is
already anchored to the same ground truth (plate + cropped refs + cropped
text), and inheriting neighbour output turns out to be a liability: each
tile's small registration drift compounds into the next (measured along one
row: +1.5, −2.1, −9.3, −15.5 px). `border_mode=overlap` (the default) instead
lets every tile denoise its whole window — the border is pure overlap for the
crossfade — and anchors each tile to its own conditioning. The drift probe in
the log (`drift dx,dy px`, cross-correlation of tile vs plate) is how you
verify this on a run.

Seam strategy in overlap mode:

* `seam_regen` (default 32px) grows tile masks across shared edges so each
  seam strip is **generated by both neighbours**.
* `seam_direction=forward` (default): the earlier tile grows into the later
  tile's side, so the later tile keeps its full border. (`back` is the legacy
  direction.)
* `seed_mode=global`: ONE noise field covers the whole latent and every tile
  slices its window from it, so a strip's two generations agree instead of
  ghosting in the blend. Shared cells across temporal chunks get the same
  noise too.
* Latent write-back is a **weight-normalized accumulation**: every tile
  contributes `gen·W` with a `seam_regen`-wide ramp on interior edges, and
  each chunk is normalized by the summed weights. Doubly-generated strips are
  exact gen↔gen crossfades (no plate residue), single-owner regions come back
  at full weight, and the hero hole is weighted 0 with the ramp rising across
  the regenerated rim. The pixel compositor applies the same crossfade in
  pixel space with the feather width matched to `seam_regen`.
* In `context` mode (legacy), write-back stays sequential hard pastes —
  blended borders would corrupt the frozen context later tiles inherit.

## Per-tile conditioning

Three channels, all cropped to the tile window:

1. **DiT refs** (`ref_crop=per_tile`): the first video reference block — and
   with `image_ref_crop=per_tile` (default) the first image block — are
   cropped to the tile's window, mapped proportionally onto their own latent
   grids. Use `image_ref_crop=whole` for identity stills / character sheets
   that are not aligned views of the frame.
2. **Text** (optional `clip` input + `prompt` widget): the stock ref node
   shows Qwen the WHOLE frame, so the baseline text embedding describes the
   full shot to every tile — at entry 1.0 that paints the subject into tiles
   that don't contain it (the "ghost subject" failure). With `clip` wired,
   each tile's embedding is re-encoded from the same cropped reference the
   DiT sees. All windows are encoded up front so the text encoder loads once.
   `prompt` must be the text given to the ref node — the node warns loudly if
   it is left empty.
3. **In-band guides** (AddGuide): always cropped to the gen's grid regardless
   of `ref_crop`. The guide latent must sit on the plate's exact grid — the
   node fails fast naming the required size if it doesn't.

With conditioning exact, the guide stays CLEAN on real footage:
`guide_noise 0`, no pixel grain. Detail comes from `guide_release` (the
phase-split tail release above). Fine-band guide noise looks good on frame 0
but ghosts moving parts in later frames; reserve small full-band values
(~0.2) for deliberate synthesis windows (hero lipsync via
`hero_guide_noise`). The Guide Grain node remains for stylized texture
mandates -- it trades fidelity for detail at every amplitude.

## Working recipe (v3, validated)

```
border_mode     overlap          seam_regen      32
seam_direction  forward          seed_mode       global
context_border  64               ref_crop        per_tile
image_ref_crop  per_tile         guide_noise     0
guide_release   0.8              frame_match     dc
motion_adapt    on               motion_release_floor 0.0
fine_below_sigma 0.75            sampler_fine    euler
sigmas          1.0, 0.7, 0.4, 0.0   (1 turbo head + 2 euler tail)
dc_match        off              pixel_color_match off
clip            wired, prompt = the ref node's prompt
conditioning    video ref + image ref + guide, CLEAN (no added noise
                anywhere), no second AddGuide at the guide's frame
```

Measured on the reference clip: +67% tile-local detail over the frozen-border
baseline at near-baseline shimmer, run-2-class full-frame detail (129.6 vs
130) with the best end-of-clip persistence ever recorded (103.6 vs 91), a
dead chunk boundary, and thin-edge-only diffs against the faithful baseline.

### Why this schedule (the laws behind v3)

* **Guide release is phase-split, not global.** The in-band guide is a
  spectrum clamp: the model matches its softness, vetoing detail LoRAs.
  Corrupting the guide for ALL steps (guide_noise, pixel grain) releases the
  clamp but re-decides content -- detail changes, faint content (smoke)
  erases, and per-frame corruption shimmers while persistent corruption
  reads as CONTENT and ghosts (both measured). `guide_release` noises the
  guide only for the fine tail: the head decides structure under full
  evidence, the tail textures under freedom, and by the handoff enough
  signal is committed that content cannot change.
* **The tail needs capacity, not just freedom.** One released step saturates
  (release 0.5 -> 0.8 moved detail <1%): a single jump is a conservative
  posterior mean that can only sharpen. Two tail steps let texture be BORN
  then ORGANIZED (+67%). Three overfeed: +7% energy that reads as hardness,
  with +17% shimmer. The capacity curve has a peak at two.
* **Euler for the tail, never a multistep sampler.** LMS extrapolates the
  previous step's derivative -- in a released tail that direction contains
  fresh per-frame texture, and the extrapolation commits it as grain
  (measured: switching the identical schedule to euler gave +56% detail AND
  cut shimmer by a third). Momentum and freedom don't mix.
* **More head = more obedience.** A second turbo head step converges the
  handoff state tighter onto the soft guide and the tail loses raw material
  (-21% detail, measured). One head step is correct. It is also a SAFETY
  rule: the distilled turbo model stepped twice through mid sigmas emitted
  NaNs into the latent (fp16, measured once at a 1.0->0.76->0.53 head;
  `hf nan` on the tile line is the tell).
* **Source shimmer is inherited, not created.** A low-res source whose own
  fine band churns (measured 0.28-0.62 frame-to-frame on a 1792px gen)
  upscales into magnified swimming: the refine LIFTS coherence toward its
  ~0.75 ceiling (0.40 -> 0.75 measured) but never past it, and neither
  release, schedule, sampling-noise coherence, nor pre-stabilizing the
  plate moves the ceiling. Fix the worst sources before generation or
  accept the ceiling + the MC post pass at delivery.
* **frame_match is the stability layer — and it must be TRANSIENT-only.**
  One global DC offset per channel per frame, matched to the plate after
  assembly: pins the exposure arc and kills the chunk-entry transient with
  zero spatial structure. This is what lets per-tile dc_match and
  pixel_color_match stay OFF (both drew tile seams and dragged the grade).
  The critical subtlety: refinement legitimately moves the latent's static
  per-channel mean away from the soft plate's. Anchoring the FULL offset to
  the plate drags the refined canvas ~1.4 off-manifold in latent space and
  the VAE decodes it as mush — measured as a 319 → 87 tile-detail collapse
  that only appeared in chunked full-frame runs (the unchunked pixel path
  bypasses the matched latent, which is why solo runs hid it for weeks).
  The node now subtracts the time-mean of the offset before applying it:
  arc and chunk transients are corrected, the refined-vs-plate static
  character is preserved. Fix verified: chunked-full returned to solo-class
  detail (78–112% of the single-tile benchmark, vs 27–52% broken).
* **Metric caveat:** Laplacian energy ranks etchers above drawers -- a LoRA
  that presses harder on edges outscores one that draws finer organic
  structure. LoRA comparisons are settled by faces and jewelry at 1:1, not
  by the benchmark.

Second hops (e.g. 2× → 4K) enter at reduced sigma — custom sigmas
`1.0, 0.923, 0.55, 0.0` class schedules keep the (1−σ) plate anchor alive and
kill threshold-level invention. Never launder detail away between hops: the
second hop's plate is the first hop's output (pixel-resized on a legal ref
grid), not a re-softened intermediate.

## v4: the detail relay (anchor + inherit)

v3 set the stability frontier; v4 sets the detail ceiling on top of it with
two pieces:

1. **Guide Anchor** (`TesseraAnchor`): splice a DETAILED still into the
   guide clip at any frame (`plate clip + detailed frame -> Guide Anchor ->
   AddGuide`; chain one node per anchor still). Default `texture` mode keeps
   the PLATE's low band (geometry, lighting -- pop-proof by construction)
   and transplants only the anchor's fine band after auto shift-correction,
   so the still does NOT need to be pixel-aligned -- any detailed frame
   from any image pipeline works. A shift estimate above 8px is refused as
   a false lock (measured: the correlator chasing a Qwen-redrawn subject
   reported (+11,-30)px on a static camera) and the splice runs unshifted
   with a warning. `strength` > 1 amplifies the mandate. `spread` (r68)
   carries the fine band outward BOTH directions for up to that many
   frames: two-level block flow (1/8-res wide match + 1/2-res refinement),
   composed so the texture is resampled once per frame, drift re-anchored
   against the anchor frame every step, confidence-gated where the warped
   structure stops matching the plate, full strength across the VAE
   packing group (+-2f), linear decay beyond. Runs on the GPU (idle in the
   preamble) when available. Spot-anchor law (183/186/189, 4x and 2x):
   only frame 0 relays detail forward on its own; a mid-clip 1-frame
   splice is a +-2 frame blip -- VAE packing averages it away and
   mid-guide detail does not propagate. `spread` is what gives mid/last anchors their reach (validated synthetically: warped-detail corr 0.63 at +-7 frames through motion). r73: the spread weight is a PURE linear taper from the anchor frame -- the r68 full-strength plateau over the packing group ended in a hard cliff (measured: adjacent-corr 0.96 0.95 0.25 0.99 at an 8K head, the frame-2->3 pop; at spread 24 the same flaw read as a ~1s ease-in ghost of flow-warped anchor texture). The plateau rationale never applied at frame 0 (head token = 1 px frame); it is shelved for mid-clip anchors. Default spread is 4 (frame-0 anchors need no reach -- the model relays head detail natively, per the 183 curve). SPLICE-SCALE LAW (r73, runs 215/217/218): the pixel splice is a 2x TOOL. The anchor's texture and the model's generated texture are two different renderings; any time-varying splice weight is a visible crossfade between them (cliff = pop, taper = morph, long spread = drift ghost -- all measured). At 2x the textures agree and the splice relays real detail; at 4x+ leave the anchor input UNPLUGGED: the no-splice control (218) showed a perfectly smooth head (adj corr 1.00 from f1) at the same head detail as the anchored run's steady state -- the Qwen still's value at big hops flows through the ReferenceToVideo attention ref instead. Anchor-grade texture at 4x+ is the phase-2 problem (model-rendered, not spliced). RELAY-RELEASE LAW (runs 219/220/221, 1x A/B/C): the anchor relay IS the model re-rendering the anchor texture in its released tail steps -- with motion_adapt clamping release to 0.00 the relay cannot run and the splice degrades to a visible crossfade (head adj-corr 0.90 default vs 0.96-0.97 with release freedom; the same mechanism measured 0.67 at 4x). House setting WHEN ANCHORING: motion_release_floor 0.3 (keeps motion_adapt armed, guarantees the relay its freedom; also lifts steady detail 34.9 -> 35.2). Floor 0.0 remains correct for unanchored fast-motion work; floor 0.3 on fast clips is unpriced (swimming risk) -- A/B pending, as is the 4x confirmation. FLAT-TILE LAW (r74, coin-on-grey stress plate): a tile whose plate crop has no fine-band energy gives the model zero evidence and total freedom -- the ref2va checkpoint painted the reference FACE into every empty tile once release opened (floor 0.3), and per-tile text re-encode makes it worse (blank crop + global prompt). `flat_skip` in Extra Options (r75 semantics) skips featureless windows: they keep the plate (featureless content is already perfectly rendered; a skipped window cannot hallucinate) and sampling time drops with them. Four design rules, each bought with a measured failure: the evidence is PIXEL-SPACE, not latent (two latent metrics were falsified in a row -- the 1-cell Laplacian, r75, and a fine+mid two-band read, r76, both sit on a broadband VAE carrier that compresses real content to 1.7-6.5x of floor: a greenscreen plate's SOFT FACES scored below boat-wood edges and were skipped, runs 238/239, while the SAME tiles separated 9-188x in pixel space; Tessera Streamed Encode measures fine-band energy per block per frame on the SOURCE pixels -- the only sharp image in the graph (the 4x-upscaled plate has no top-octave energy by construction: soft faces read 2.7x floor on the plate vs 38-43x for hard frame borders, run 240 -- one octave less blind than the latent, same disease); one block maps to ~128px on the target and rides the stats to the refine through the conditioning -- without them flat_skip prints a note and stays OFF rather than guessing blind, and a frame-count mismatch, i.e. a re-timing node between encode and refine, also disables it); the score is the BLOCK-MAX, not the tile mean (the r74 mean averaged a coin-top sliver into "flat" and cut a 24/255 band straight across the coin, run 236 -- the max refuses to skip any tile the subject ever touches); the threshold is a RATIO to the clip's own block-energy floor (median block), so it self-calibrates across source grain/compression with no calibration run -- flat noise can only peak at ~2-3x its own median (coin plate 2.7-2.8x) while content clears by multiples (soft faces 9x+, coin sliver 15x, ground dust 41x, hero 502x, all pixel-measured), default 4.0, 0 = off; and the decision is PER (TILE, CHUNK) -- the model only sees its own window, so a tile the subject exits before a later chunk is EMPTY in that window (the exact 234 hallucination setup) and skips there while refining where the subject is, the handoff invisible by construction because it only occurs across content flat on both sides (refined-flat == plate-flat: grain 0.0011 vs 0.0012, seam ratios ~1, run 236). Heroes never skip; values below 1.0 (stale absolute-era widgets) trigger a loud warning. Also r74: the dilation budget's cap shrink is clamped by CLIP LENGTH (tokens = tile area x min(window, clip); a 90-frame clip under x1.61 dilation now keeps the full 1024 cap instead of dropping to 768), and the anchor false-lock limit scales with resolution (8px per 1088 rows).
2. **`guide_inherit`** on Tessera Refine: each later temporal chunk's
   guide frames before its generated range are replaced by the
   already-refined latent canvas -- rendered detail becomes the next
   chunk's evidence, aligned and graded by construction.

Chunk 1 renders the anchor's texture; every later chunk inherits the
previous chunk's render as truth. Measured (same encoder conditions):
+60% detail over v3 across the whole clip, FLAT from f73 to f110 (the decay
that defined every corruption-based approach is gone), frame-0 at the
noise-corruption ceiling, f0->f1 step 5.3 vs 4.7 anchorless (the raw
unaligned splice popped at 30), chunk boundary and grade at v3 levels.
The detail ceiling is now set by a single still from any image pipeline,
and the video model propagates it. Guide corruption is fully retired.

## Tiling widgets (v2.1)

`spatial_tile`: high_vram / low_vram / custom (custom = manual
`tile_width`/`tile_height`; was "off"). `temporal_tile`: high_vram
(124-frame windows) / low_vram (73) / custom (`temporal_size`, literal,
never dilation-scaled) / off (whole clip in one window — the quality
lane; chunked flicker is starved windows x boundaries, and unchunked
has no boundaries). high/low_vram mean REAL content frames and
auto-scale under dilation with the tile cap shrinking in step (see the
Dilate row). Legacy integer/"off" values from old workflows resolve
sensibly (int = custom-equivalent, unscaled).

| hf probe | every tile logs `hf` — Laplacian energy of the sampled latent before write-back. If two runs' `hf` bands match but the outputs differ, the sampler is exonerated: the divergence is in assembly or decode. This is the one-line diagnostic that localized the frame_match bug. |

## Grid laws (unchanged, still load-bearing)

One addition: a half-res ref often arrives CANVAS-SQUEEZED (84x48
against a 172x96 plate — ratio 2.05, non-integer), which blinded the
ref-scale detection and silently sent every tile's ref crop down the
fractional-resample path whenever tile sizes missed the 64px grid by
luck. The detection now tolerates the squeeze (intended ratio within
8%), sizes tiles on the corrected grid, and the resample warning —
which caught this bug within an hour of being colorized — should not
appear on auto-tiled runs.

Everything is computed in latent cells; off-grid inputs raise errors naming
the nearest valid values. Reference latents must sit at an integer ratio to
the plate (q=2 → 64px snap, q=3 → 96px); fractional ratios resample the ref
into corruption. Pixel-space resizing is legal, latent interpolation is not.
